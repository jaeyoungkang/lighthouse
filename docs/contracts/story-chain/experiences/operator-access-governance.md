# Operator access governance

Light House 운영자는 초대 연구자의 제품 접속 범위를 관리한다. 비공개
운영 기간에는 내부 사용자와 초대받은 외부 연구자를 구분해야 한다. 운영자는
현재 접속 가능한 외부 이메일을 확인하고, 초대 상태를 직접 바꾼다.

운영자가 변경을 확정하면 이후 인증 요청은 최신 결정을 따른다. 실패한 변경은
기존 접속 상태를 바꾸지 않는다. 운영자는 화면에서 변경이 적용됐는지 확인할
수 있다.

이 Experience는 제품 접속 허용을 관리하는 내부 운영 경험에 한정한다. 연구자가
논문을 검색하고 탐색하는 경험과 Story Chain release 상태를 점검하는 경험은
각각 다른 Experience가 소유한다. 내부 관리자 자격과 일반 제품 접속 자격도
이 Experience 안에서 서로 구분한다.
