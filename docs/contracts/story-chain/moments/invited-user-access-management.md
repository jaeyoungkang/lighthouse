# Invited user access management

운영자는 비공개 운영 기간에 현재 초대된 외부 연구자를 확인한다. 새 연구자를
초대하거나 기존 초대를 끝낼 때 접속 이메일을 추가하거나 삭제한다. 제품은
변경 결과와 현재 유효한 외부 접속 목록을 같은 관리 흐름에서 보여 준다.
