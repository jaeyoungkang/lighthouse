# Search results first review

연구자가 새 연구를 시작하거나 진행 중인 연구에 지금 필요한 논문을 찾기 위해
검색어를 제출했다. 검색 결과를 처음 보면, 먼저 분야의 흐름과 읽을 후보를
빠르게 가려야 한다.

이 Moment는 첫 10편 노출, 검색 완료 반응, 보이는 논문부터 시작되는
인라인 분석을 포함한다. 사용자는 결과 목록에서 분야의 흐름을 파악하고,
다음에 볼 논문과 후속 탐색 방향을 정한다.
