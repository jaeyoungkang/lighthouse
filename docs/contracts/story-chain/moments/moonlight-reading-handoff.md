# Moonlight reading handoff

연구자가 검색 결과, 인용 계보, 그래프 이웃에서 더 읽을 가치가 있는 논문을
고른다. 이때 필요한 것은 Light House 안에서 PDF를 다시 여는 것이 아니라,
현재 탐색 맥락을 보존한 채 본문 정독 도구로 빠르게 넘어가는 흐름이다.

Light House는 PDF가 있는 논문 카드의 진입을 Moonlight 외부 읽기 링크로
연결한다. 사용자는 탐색과 비교는 Light House에서 계속 유지하고, 논문 본문
정독은 Moonlight에서 이어 간다.
