# Search from any screen

연구자는 어떤 화면에서도 새 검색을 바로 시작할 수 있어야 한다.

Light House는 모든 탐색 화면 상단에 검색창 하나를 제공한다. 연구자는 이
검색창에서 새 논문 검색을 시작한다.

새 검색을 시작하면 주소가 검색 조건에 맞게 바뀌고, 결과가 그 주소에서 열린다.
인용 관계, 비슷한 논문 탐색, 연구 공백 리포트도 주소로 구분된다. 브라우저에서
뒤로 가면 직전에 보던 화면으로 돌아간다.
