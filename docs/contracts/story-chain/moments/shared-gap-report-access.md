# Shared gap report access

연구자가 자신이 만들었거나 다른 연구자가 공유한 연구 공백 리포트 주소를 열어
같은 분석을 함께 읽으려 한다. 이때 리포트를 만든 사람인지보다 Light House
가입자인지와 어떤 리포트 주소를 열었는지가 접근 기대를 결정한다.

이 Moment는 저장된 리포트를 주소로 다시 열고, 같은 입력으로 이미 준비된
리포트를 재사용하며, 연구자마다 자신의 반응을 유지하는 상황을 다룬다. 검색
결과에서 새 공백 분석을 시작하는 순간과 리포트 안에서 다음 검색을 시작하는
순간은 각각 다른 Moment가 소유한다.
