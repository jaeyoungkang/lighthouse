# Gap analysis from results

연구자가 검색 결과를 본 뒤 `연구 공백 찾기`를 선택한다. 이미 나온 논문
목록만으로는 연구 흐름 사이의 빈자리를 판단하기 어렵다. 사용자는 결과
논문들이 어떤 묶음으로 나뉘는지 보고, 새 연구 질문 후보가 생길 만한
공백을 찾으려 한다.

Light House는 검색 결과 논문들을 클러스터로 묶고, 클러스터 사이에
기대보다 연결이 적은 지점을 찾아 gap report artifact로 저장한다.

이 Moment에서 사용자는 상단 그래프로 클러스터와 gap 후보의 위치를 보고,
클러스터를 선택해 그 묶음이 어떤 연구 작업을 대표하는지 확인한다. gap
후보를 선택하면 정량 score 대신 정성 설명, 근거가 붙은 연구 가설, 다음에
파고들 만한 방향을 읽는다. gap report는 검색 결과보다 넓은
폭을 써서 그래프가 답답하게 잘리지 않게 하고, 하단 본문 리포트는 분석된
분야, 클러스터 배경과 차이, 공백 추론 방법을 한 번에 조망하게 한다.
