# Archive

완료된 작업의 기록 중 보존 가치는 있으나 현재 작업이 직접 읽지 않는 문서를
모은다. 이 디렉터리는 정본이 아니다. 현재 제품 의미는 Story Chain, 운영
절차는 `docs/*.md` 정본이 소유한다. 여기 문서는 당시 판단의 근거를 재현할
때만 읽는다.

여기로 옮긴 문서는 옮긴 시점 이후 갱신하지 않는다. archive 문서가 다시 현재
작업의 근거가 되면 정본 위치로 승격하고, 이 README에서 그 사실을 남긴다.
